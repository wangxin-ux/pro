# 参考站行为记录

- 顶部跑马灯高度为 `50px`，内容轨道使用 `translate3d` 持续匀速横向移动；单项高度 `28px`、宽度 `420px`、左右内边距 `12px`。
- 主导航位于普通文档流中。参考站从 `scrollY=0` 滚到 `scrollY=500` 后，导航纵坐标从 `116px` 变为 `-384px`，没有吸顶、缩小或阴影状态。
- 导航链接使用约 `0.3s` 的过渡。
- 主按钮颜色、背景与边框过渡均为 `0.3s`。
- 筛选菜单为点击展开；本项目保留轻微淡入位移动效。
- Skill 卡片沿用项目原交互，只保留进入淡入和封面轻微缩放。
- `prefers-reduced-motion` 下停止跑马灯及其他新增动效。

# Welcome Page Behaviors

- The page is fixed to one viewport and does not scroll.
- Background dots remain stable while broad grayscale bands drift diagonally.
- Small points vary opacity over time, producing the source site's shimmering field.
- Header links and buttons translate upward by about 1-2px on hover.
- Primary CTAs gain a brighter border and wider soft shadow on hover.
- The code card floats vertically by roughly 6px on a slow alternate loop.
- Clicking `Browse Components` reveals the existing Skill library in the same app.
- Keyboard activation works through a native button.
